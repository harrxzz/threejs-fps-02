SABLE LINE — a round-based tactical FPS in three.js. Single-player vs bots on an original map: Buy (12s) → Combat (100s) → Buy rounds, first to 5 wins, bomb plant/defuse, money and a buy menu, multiple weapons and a grenade. Bots patrol, guard, attack, investigate and defuse, with human-like reaction times and bursts.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
